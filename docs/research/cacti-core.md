# Cacti core behavior

Research for [#20](https://github.com/somethingwithproof/plugin_cloud/issues/20), run 2026-11-14. Question: does every Cacti API and behavior the plan names hold at `release/1.2.31` and on the current `1.2.x` branch?

**Result.** All sixteen named functions have the same signature at both refs, and every hook the plan uses is called by core with the arguments recorded below. Two plan statements were wrong: Maint's `is_device_in_maintenance` hook has no caller (Thold and core call `plugin_maint_check_cacti_host()` directly), and a device template carries no availability setting. Several rows were imprecise and are corrected in the plan; the [Plan corrections](#plan-corrections) list is what changed. A script server data query was run on a device with availability None at 1.2.31.

Rows were read from source with `git show` and `git grep` unless marked as executed.

## Later plugin integration coverage
